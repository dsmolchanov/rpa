# Question Format Guide

Required clarifications for AI-DLC flows should be written to markdown files rather than handled only in chat.

## Requirements

- Store question files under `aidlc-docs/inception/questions/`
- Use concise prompts
- Prefer short multiple-choice options when possible
- Collect the user's response in an `[Answer]:` field

## Template

```markdown
# Question: [short title]

## Context
[Why this answer is needed]

## Question
[Concrete question text]

## Options
- A. [option]
- B. [option]
- C. [option]

[Answer]:
```
