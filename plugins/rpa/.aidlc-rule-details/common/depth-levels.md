# Depth Levels

The compatibility layer uses three depth values:

- `minimal`: concise artifacts for low-risk work
- `standard`: normal artifact detail for typical work
- `comprehensive`: highest-detail artifacts for risky or ambiguous work

## Important

Depth controls the level of detail inside executed stages.

Depth does **not** decide whether a stage runs. Stage execution decisions belong in `aidlc-docs/inception/plans/execution-plan.md` as `EXECUTE` or `SKIP`.
